# ShiftByte GitHub baseline

This repository defines the shared contribution and collaboration baseline for repositories in the ShiftByte organization. It describes how contributors work; detailed product architecture, environments, deployment, and release guidance belongs in the relevant project repositories.

GitHub uses [`.github/pull_request_template.md`](.github/pull_request_template.md) and the forms under [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) as defaults for organization repositories that do not provide their own templates. GitHub applies organization-wide community health defaults only when this repository is public.

Organization-wide guidance establishes the general standard. Repository-specific instructions supplement it and take precedence when they are more specific or restrictive. Because the organization currently uses GitHub Free with private repositories, some review and branch policies are procedural expectations rather than technically enforced controls.

See the [contribution guide](CONTRIBUTING.md), [security policy](SECURITY.md), and [AI-assisted development rules](AGENTS.md).
